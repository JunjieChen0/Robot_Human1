## 组织与运行

远程同学使用[Linux下载与启动说明](model_judgment_remote_quickstart.md)，无需Python运行环境大包，只下载GitHub源码后运行启动脚本。该简明指南不包含组织者判定答案，可单独转发给参与者。

安装项目依赖后运行 `python -m streamlit run app.py`，在侧栏选择“模型判断”。已入库的实验文件可直接展示，无需先训练；缺产物时按README重建。

首次测试前向参与者提供下方两项任务，不提前展示标准答案或组织者判定依据。记录页面版本、设备、既往页面/源码/答案接触、是否接受提示。先保存首次回答，再查看解释或提示；事后修正与首次回答分开保留。

## 固定任务

1. 指出打乱哪项输入后，模型表现下降最多，并用图中读数说明。点击一项输入，找到它的含义、分布、样本量；在正确与错误案例中核对该输入值、真实标签和模型输出。
2. 说明这张图能否用于判断个人患病原因，并解释理由。还可以指出它是否解释了某一条记录为什么判错。

## 组织者判定依据（首次测试后再提供）

任务1应比较**平均下降值**，不是标准差长度、原始输入值大小或分布样本数。在本图五项中找到均值最大的特征，数值单位应为百分点；按当次冻结产物核对，不把“所有输入中第一”作为结论。图中橙色横线是30次置换的均值±1标准差，不是95%置信区间。

任务2的核心是“不能判断个人患病原因”：固定模型的整批样本依赖实验不证明因果，也不是局部归因。看到正确/错误案例只说明相应输入、标签与预测，不能据此断言某项输入导致了该条误判。零值/负值不表示某项习惯对健康无用或有害；饮水列为表单自动填充常量。

不要将这段判定依据复制为参与者原话。首次答案经提示修改后只能记为提示后回答，复测另列。
