## T1 导入一份档案

**从哪里开始：** 左侧“页面”选择“体重管理原型”。

**操作步骤：**

1. 在主页面找到并展开“导入个人档案（CSV）”。
2. 在“选择个人档案 CSV”处，选择组织者提供的 `profile_template.csv` 文件。
3. 点击“校验并载入档案”。
4. 向下浏览“身体与行为录入”的各组输入项，再查看“当前输入概览”。暂时不修改数据。

**操作到这里结束：** 页面提示校验通过，示例数据已经出现在表单中。

**体验反馈：** 导入入口和表单是否容易使用？有没有让你停下来找、反复确认或不愿填写的地方？请描述具体位置，也可以写顺手的地方。

按说明能找到导入区，点击校验后看到绿色成功提示，表单载入了 25 岁、身高 1.70 米、体重 70 千克，中文分组和单位方便核对。需要额外确认的是“当前输入概览”把这份示例标为“CSV 导入（用户提供，真实性未核验）”，没有继续明确它是示例数据，建议保留示例来源标识。

## T2 运行分析并查看结果

**从哪里开始：** 保持 T1 导入的档案，留在体重管理页面。

**操作步骤：**

1. 确认“同时分析体重趋势（可选）”已勾选，保留页面原有的模拟体重记录。
2. 将“每日摄入热量（kcal）”设为 1800，其他数据保持不变。
3. 点击“估计并分析趋势”，等待分析结束。
4. 在“分析结果与解释”中先看“本次结果摘要”，核对分类和两种体重来源；再查看“肥胖等级估计”、类别概率图表和“体重趋势与外推”。

**操作到这里结束：** 已看到分类结果和体重趋势，并浏览这两部分的展示。

**体验反馈：** 哪些结果最有用？你想看的信息是否容易找到？哪些卡片、图表或布局让你不知道该先看什么、该怎样使用？

最有用的是摘要把“正常体重”、分类档案 70.0 kg、趋势日志 70.5 kg 并列展示，下面还能看到最高类别概率 47.0%、日志累计变化 −1.5 kg 和每日能量差 +237 kcal。阅读图表时需要来回对应：概率表按概率高低排序，旁边柱图顺序不同；趋势图的 `day`、`weight_kg`、`segment` 仍是英文，记录与外推使用相近蓝色，建议统一顺序、改用中文并突出两段的分界。

## T3 阅读结果说明

**从哪里开始：** 接着查看 T2 生成的结果。

**操作步骤：**

1. 阅读“肥胖等级估计”附近的概率含义和结果使用提示。
2. 浏览“解释反馈”中的说明与特征重要性表。
3. 返回主页面上方，展开“数据来源与适用范围”，浏览其中的说明。

**操作到这里结束：** 已浏览结果旁的解释和“数据来源与适用范围”两处内容。

**体验反馈：** 这些说明是否足够你判断结果可以怎样使用？哪些文字有帮助，哪些太专业、太长或缺少解释？请指出具体内容，并写出希望补充什么。

“80% 不等于患病风险或绝对正确率”、整体特征重要性不能解释个人原因，以及尚未验证新群体适用性这几处说明很有帮助，能区分类别估计、记录趋势和未来外推。仍希望给“类别概率未经校准”和“SMOTE 合成记录”补一句通俗解释，让读者知道这些限制具体会怎样影响解读。

## T4 修改体重后重新分析

**从哪里开始：** 回到“身体基本信息”输入区，保留当前已有分析结果。

**操作步骤：**

1. 将“体重（千克）”改为 80，按 Enter 或点击输入框外，使修改生效；其他输入保持不变。
2. 先不点击分析按钮，向下查看“当前输入概览”附近的提示和已有结果。
3. 点击“估计并分析趋势”，等待分析结束。
4. 在结果摘要下找到“修改前后对比”，查看“分类已改变 / 未改变”的说明，以及改变的输入与结果。

**操作到这里结束：** 修改后的分析已完成，并已查看“修改前后对比”。分类是否变化均按实际情况观察。

**体验反馈：** 从修改输入到更新结果，页面有没有让你不确定是否需要重算、结果是否已更新？前后对比是否方便？希望怎样调整？

把体重改成 80 后按 Enter，概览更新为 80.0 kg，黄色提示明确说旧结果不对应当前编辑内容；重算后对比表显示体重 70.0 → 80.0、分类仍为“正常体重”、最高概率 47.0% → 32.7%，更新状态清楚。对比放在详细结果前很方便，日志体重仍为 70.5 kg 也有原因说明；希望对比表再标出两次提交时间，方便确认比较的是哪两次分析。

## T5 遇到输入错误后恢复

**从哪里开始：** 在体重管理页面找到“体重记录与饮食录入”，保持趋势分析开启。

**操作步骤：**

1. 将“每日摄入热量（kcal）”改为 0，点击“估计并分析趋势”。
2. 浏览页面给出的错误提示，以及此时的结果展示。
3. 将同一个输入框恢复为 1800，再点击“估计并分析趋势”。
4. 向下查看“体重趋势与外推”是否重新出现。

**操作到这里结束：** 已经历一次错误提示，并在修正输入后重新看到趋势。

**体验反馈：** 提示能否帮助你找到问题并继续操作？有没有需要猜测、反复尝试，或担心原有信息丢失的地方？请结合刚才的操作说明。

输入 0 后，红色提示指出每日摄入热量有误，分类结果保留、趋势显示“未生成”；实际点击“返回每日摄入热量”，改回 1800 并重算后，趋势图重新出现，没有重新导入档案。希望把“正的有限数值”改成“请输入大于 0 的热量值（kcal）”；错误旁还有绿色“分类分析已完成”提示，扫读时需要仔细区分分类成功与趋势失败。

## T6 提交反馈并浏览公平性审核

**从哪里开始：** 先留在体重管理页面，再通过侧栏进入审核页。

**操作步骤：**

1. 在“本次结果摘要”点击“填写用户反馈”，到达“理解自测与用户反馈”；选择操作容易程度，并按自己的理解完成页面上的单选题，建议可以留空。
2. 点击“保存本次反馈”，再点击“下载匿名反馈（JSON）”。
3. 在左侧“页面”选择“模型公平性审核”。
4. 在“查看群体”中先选择“女性”，再选择“男性”，最后回到“全部群体”。
5. 在“比较指标”中分别选择“漏判率 FNR”和“误判率 FPR”，查看对应图表与紧邻的分组指标表，浏览同时展示的基线模型和公平性约束方案。
6. 在左侧切回“体重管理原型”，查看之前的档案和结果。

**操作到这里结束：** 已试用反馈保存与下载，切换过审核页的群体和指标，并返回体重管理页。

**体验反馈：**

- 反馈入口、填写和下载过程有没有不顺手或多余的步骤？摘要中的链接能直接到反馈区；选择容易程度 4、回答“根据当前输入估计的肥胖等级”并填写建议后，保存提示清楚说明还要下载，JSON 已实际下载并能解析。保存与下载是两个按钮，需要记得完成第二步；本次没有发生保存或下载失败。
- 审核页哪些展示便于比较，哪些术语、图表或布局增加了负担？你希望怎样简化？同图展示两方案、紧邻列出样本量和漏判/误判数很方便，能看出本次两方案相同、EO 差值 0.0208 → 0.0208，没有改善。FNR/FPR 图轴用小数而表格用百分数，需要换算，EO、TPR、Wilson 等术语也较密集，建议图轴统一用百分数并给术语就近添加简短释义。
- 页面切换和返回的体验是否符合预期？如有问题，请说明。符合预期：依次切换女性、男性、全部群体及两种错误率后，返回原型仍保留体重 80.0 kg、热量 1800、正常体重分类 32.7%、日志 70.5 kg 及反馈下载按钮，分析时间仍是 17:46:03，没有被页面切换重置。
