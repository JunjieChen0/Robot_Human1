# 发给同学：模型判断页面测试

适用于Linux，已在Debian 13 / Python 3.13验证；只需CPU，不需要独立显卡。源码与实验结果从GitHub下载，运行环境不打进压缩包。首次安装依赖需要联网，后续直接启动，无需下载原始数据或训练模型。

## 下载与启动

打开 [GitHub项目](https://github.com/JunjieChen0/Robot_Human1)，点击 **Code → Download ZIP**，完整解压。

在解压后的 `Robot_Human1-main` 目录打开终端，运行：

```bash
bash start_model_judgment.sh
```

首次启动自动创建独立虚拟环境并安装页面依赖，不更改系统Python包。Debian 13如果提示缺少Python或venv，先运行 `sudo apt install python3 python3-venv`，再重试。安装成功后，再次启动会跳过依赖安装。

浏览器打开 **http://localhost:8501**，直接进入“模型判断”，无需切换其他页面。保持终端运行，完成后按Ctrl+C停止。

如果是在**通过SSH登录的服务器**上运行，在自己电脑另开终端连接并转发端口：

```bash
ssh -L 8501:127.0.0.1:8501 用户名@服务器地址
```

保持这个连接，再用自己电脑的浏览器打开同一地址。若8501已占用，服务器启动时加 `--server.port 8510`，SSH相应改成 `-L 8510:127.0.0.1:8510`，浏览器打开8510端口。
