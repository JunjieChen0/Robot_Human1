# 同学测试用深蹲计数说明

适用人群：大学生。每次仅一人，固定侧面，肩髋膝踝入镜；页面只是课堂计数工具，不评价动作是否标准。

## 打开页面

从[GitHub下载源码ZIP](https://github.com/JunjieChen0/Robot_Human1/archive/refs/heads/main.zip)并完整解压，在项目目录运行：

```bash
bash start_squat_counter.sh
```

需要Python 3.11+；Debian 13如缺venv可安装`python3 python3-venv`。首次安装页面依赖、下载官方模型资源需要联网；后续复用。浏览器打开终端显示的`http://localhost:8501`。端口占用可加`--server.port 8521`并打开8521。

远程服务器运行时，在自己的电脑用`ssh -L 8521:127.0.0.1:8521 用户名@服务器`转发相应端口，再用本机浏览器打开localhost:8521。摄像头由本机浏览器获取，需要同意权限；也可以导入已获同意的测试视频。

## 独立完成两项任务

1. 选择获同意的视频或自己的摄像头，检查站位，开始一次计数；完成/播放约定动作，中途暂停并继续，最后结束。
2. 核对画面与自动计数，指出是否有误计/漏计及时间；需要时使用撤销、补记修正，并关闭摄像头。没有发现错误也应如实说明，不能猜填。

暂停/结束后回看不计数。继续会回到暂停位置，先重新站立准备。输入新的来源或重新计数会清空本次记录，先导出要保留的结果。

填写匿名编号、完成情况、错误与修正原话、既往接触及提示情况，再保存首次反馈并导出JSON交给组织者。未知提示次数可留空，不输入姓名或学号。下一位同学使用新的浏览器会话。是否完成及能否自行纠正由组织者根据原话与操作核对，不由页面自动判分。
