## T1 导入一份档案

**从哪里开始：** 左侧“页面”选择“体重管理原型”。

**操作步骤：**

1. 在主页面找到并展开“导入个人档案（CSV）”。
2. 在“选择个人档案 CSV”处，选择组织者提供的 `profile_template.csv` 文件。
3. 点击“校验并载入档案”。
4. 向下浏览“身体与行为录入”的各组输入项，再查看“当前输入概览”。暂时不修改数据。

**操作到这里结束：** 页面提示校验通过，示例数据已经出现在表单中。

**体验反馈：** 导入入口和表单是否容易使用？有没有让你停下来找、反复确认或不愿填写的地方？请描述具体位置，也可以写顺手的地方。

按步骤展开“导入个人档案（CSV）”，上传仓库提供的 profile_template.csv，再点击“校验并载入档案”，页面出现成功提示；表单读到身高 1.70 米、体重 70.0 千克，数据是示例而非我的健康记录。字段分组和单位便于核对；导入入口默认折叠，这次有明确步骤指引，未检验没有指引时能否自行发现。

## T2 运行分析并查看结果

**从哪里开始：** 保持 T1 导入的档案，留在体重管理页面。

**操作步骤：**

1. 确认“同时分析体重趋势（可选）”已勾选，保留页面原有的模拟体重记录。
2. 将“每日摄入热量（kcal）”设为 1800，其他数据保持不变。
3. 点击“估计并分析趋势”，等待分析结束。
4. 向下浏览“分析结果与解释”中的“肥胖等级估计”、类别概率图表，以及“体重趋势与外推”。

**操作到这里结束：** 已看到分类结果和体重趋势，并浏览这两部分的展示。

**体验反馈：** 哪些结果最有用？你想看的信息是否容易找到？哪些卡片、图表或布局让你不知道该先看什么、该怎样使用？

我看到“正常体重”、最高类别概率 47.0%、最高与第二高差值 12.3%，以及日志最新体重 70.5 kg、每日能量差 +237 kcal；分类是在估计当前输入所属的肥胖等级，趋势使用另一组模拟日志和能量外推。分类卡片便于定位，但概率表、图表、特征重要性和趋势纵向排列较长，建议在结果顶部先汇总分类、趋势及各自采用的体重。

## T3 阅读结果说明

**从哪里开始：** 接着查看 T2 生成的结果。

**操作步骤：**

1. 阅读“肥胖等级估计”附近的概率含义和结果使用提示。
2. 浏览“解释反馈”中的说明与特征重要性表。
3. 返回主页面上方，展开“数据来源与适用范围”，浏览其中的说明。

**操作到这里结束：** 已浏览结果旁的解释和“数据来源与适用范围”两处内容。

**体验反馈：** 这些说明是否足够你判断结果可以怎样使用？哪些文字有帮助，哪些太专业、太长或缺少解释？请指出具体内容，并写出希望补充什么。

结果旁直接写明“80% 类别概率不等于 80% 患病风险或正确率”，展开“数据来源与适用范围”后也能看到国家、合成记录及尚未验证其他人群的限制，据此不能直接推断所有大学生的健康状况。特征重要性已有中文说明和全局、非因果提示，但“训练集中位数填充”“横断面”等仍偏专业，建议补充一个“0.326 不代表个人风险 32.6%”的短例子。

## T4 修改体重后重新分析

**从哪里开始：** 回到“身体基本信息”输入区，保留当前已有分析结果。

**操作步骤：**

1. 将“体重（千克）”改为 80，按 Enter 或点击输入框外，使修改生效；其他输入保持不变。
2. 先不点击分析按钮，向下查看“当前输入概览”附近的提示和已有结果。
3. 点击“估计并分析趋势”，等待分析结束。
4. 向下找到“修改前后对比”，浏览改变的输入与结果。

**操作到这里结束：** 修改后的分析已完成，并已查看“修改前后对比”。分类是否变化均按实际情况观察。

**体验反馈：** 从修改输入到更新结果，页面有没有让你不确定是否需要重算、结果是否已更新？前后对比是否方便？希望怎样调整？

体重改为 80 kg 并按 Enter 后，概览更新，页面提示“输入已修改，请重新分析”，原结果仍为正常体重、47.0%；重算后分类仍为正常体重，最高概率变为 32.7%，差值变为 2.0%，前后对比列出了体重 70.0 → 80.0。趋势仍从日志的 70.5 kg 起算，能量差仍为 +237 kcal，页面也说明两种体重不同；建议把前后对比移到结果顶部，并并列说明分类体重与趋势体重。

## T5 遇到输入错误后恢复

**从哪里开始：** 在体重管理页面找到“体重记录与饮食录入”，保持趋势分析开启。

**操作步骤：**

1. 将“每日摄入热量（kcal）”改为 0，点击“估计并分析趋势”。
2. 浏览页面给出的错误提示，以及此时的结果展示。
3. 将同一个输入框恢复为 1800，再点击“估计并分析趋势”。
4. 向下查看“体重趋势与外推”是否重新出现。

**操作到这里结束：** 已经历一次错误提示，并在修正输入后重新看到趋势。

**体验反馈：** 提示能否帮助你找到问题并继续操作？有没有需要猜测、反复尝试，或担心原有信息丢失的地方？请结合刚才的操作说明。

把每日摄入热量改为 0 后点击分析，出现“每日摄入热量必须为正的有限数值，请检查后重新分析”，分类结果仍为正常体重、32.7%，该次趋势不显示。将同一输入框恢复为 1800 后再次分析，趋势及 +237 kcal 重新出现，没有重新导入档案；提示指出了字段和修正方向，建议增加回到该输入框的定位入口。

## T6 提交反馈并浏览公平性审核

**从哪里开始：** 先留在体重管理页面，再通过侧栏进入审核页。

**操作步骤：**

1. 在结果下方找到“理解自测与用户反馈”，选择操作容易程度，并按自己的理解完成页面上的单选题；建议可以留空。
2. 点击“保存本次反馈”，再点击“下载匿名反馈（JSON）”。
3. 在左侧“页面”选择“模型公平性审核”。
4. 在“查看群体”中先选择“女性”，再选择“男性”，最后回到“全部群体”。
5. 在“比较指标”中分别选择“漏判率 FNR”和“误判率 FPR”，查看对应图表与紧邻的分组指标表，浏览同时展示的基线模型和公平性约束方案。
6. 在左侧切回“体重管理原型”，查看之前的档案和结果。

**操作到这里结束：** 已试用反馈保存与下载，切换过审核页的群体和指标，并返回体重管理页。

**体验反馈：**

- 反馈入口、填写和下载过程有没有不顺手或多余的步骤？已选择操作容易程度 4 和“根据当前输入估计的肥胖等级”，保存后看到成功提示，并实际下载了匿名 JSON，文件可解析且包含所选答案与建议。流程可完成，但入口位于结果末尾，需要经过较长的结果区；建议增加直达反馈区的入口。
- 审核页哪些展示便于比较，哪些术语、图表或布局增加了负担？你希望怎样简化？已依次切换女性、男性、全部群体，并分别选择漏判率 FNR、误判率 FPR；两方案并排图和漏判、误判数便于核对，顶部也明确提示本次没有改善（EO 0.0208 → 0.0208）。分组表列数较多，缩写和区间表增加阅读量，建议先呈现样本量、漏判数、误判数及两种错误率，其余详细指标折叠；女性本次零错误不能证明完全公平或未来无错误，另已展开不确定性说明。
- 页面切换和返回的体验是否符合预期？如有问题，请说明。返回体重管理页后，实测输入仍为 80.0 kg 和 1800 kcal，分类仍为正常体重、32.7%，趋势仍在，日志最新体重仍为 70.5 kg；本次未遇到档案或结果丢失。仅验证同一会话的切换返回，没有验证刷新、关闭或跨会话恢复。
