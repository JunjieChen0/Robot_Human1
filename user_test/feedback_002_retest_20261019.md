## T2 运行分析并查看结果

**从哪里开始：** 保持 T1 导入的档案，留在体重管理页面。

**操作步骤：**

1. 确认“同时分析体重趋势（可选）”已勾选，保留页面原有的模拟体重记录。
2. 将“每日摄入热量（kcal）”设为 1800，其他数据保持不变。
3. 点击“估计并分析趋势”，等待分析结束。
4. 在“分析结果与解释”中先看“本次结果摘要”，核对分类和两种体重来源；再查看“肥胖等级估计”、类别概率图表和“体重趋势与外推”。

**操作到这里结束：** 已看到分类结果和体重趋势，并浏览这两部分的展示。

**体验反馈：** 哪些结果最有用？你想看的信息是否容易找到？哪些卡片、图表或布局让你不知道该先看什么、该怎样使用？

新增“本次结果摘要”先给出正常体重，并并列显示分类档案体重 70.0 kg、趋势日志体重 70.5 kg，还写出模拟日志 72.0 → 70.5 kg、合计 -1.5 kg；分类和趋势的来源可以在同一区域核对。继续查看详细结果时，最高类别概率为 47.0%、前两类差值 12.3%，趋势能量差 +237 kcal；主次顺序较上轮清楚，但完整结果区仍较长，摘要中的跳转链接值得保留。

新版用“整体相对依赖哪些信息”解释重要性，并给出“0.326 不代表个人有 32.6% 患病风险”的例子；横断面调查和中位数也增加了普通语言解释，中文指标表更易对应输入。实际查看概率提示及适用范围后，我的回答是：类别概率 80% 不是患病风险或绝对正确率，也不能把结果直接推广为所有大学生的健康结论；SMOTE、Wilson 区间等术语仍可配短例子，但本次已有资料接触，不能当作首次理解成绩。

## T4 修改体重后重新分析

**从哪里开始：** 回到“身体基本信息”输入区，保留当前已有分析结果。

**操作步骤：**

1. 将“体重（千克）”改为 80，按 Enter 或点击输入框外，使修改生效；其他输入保持不变。
2. 先不点击分析按钮，向下查看“当前输入概览”附近的提示和已有结果。
3. 点击“估计并分析趋势”，等待分析结束。
4. 在结果摘要下找到“修改前后对比”，查看“分类已改变 / 未改变”的说明，以及改变的输入与结果。

**操作到这里结束：** 修改后的分析已完成，并已查看“修改前后对比”。分类是否变化均按实际情况观察。

**体验反馈：** 从修改输入到更新结果，页面有没有让你不确定是否需要重算、结果是否已更新？前后对比是否方便？希望怎样调整？

改为 80 kg 并按 Enter 后，输入概览已为 80.0 kg，而未重算的结果摘要仍标明采用 70.0 kg，同时显示待重算提示；重算后摘要更新到 80.0 kg，趋势体重仍为 70.5 kg。对比已移到详细分类前，明确写出“分类未改变：正常体重；最高类别概率 47.0% → 32.7%”，并列出体重 70 → 80 kg，比上轮易定位；后续再次提交会换成最近两次提交的比较，建议在标题旁说明这个基准。

## T5 遇到输入错误后恢复

**从哪里开始：** 在体重管理页面找到“体重记录与饮食录入”，保持趋势分析开启。

**操作步骤：**

1. 将“每日摄入热量（kcal）”改为 0，点击“估计并分析趋势”。
2. 浏览页面给出的错误提示，以及此时的结果展示。
3. 将同一个输入框恢复为 1800，再点击“估计并分析趋势”。
4. 向下查看“体重趋势与外推”是否重新出现。

**操作到这里结束：** 已经历一次错误提示，并在修正输入后重新看到趋势。

**体验反馈：** 提示能否帮助你找到问题并继续操作？有没有需要猜测、反复尝试，或担心原有信息丢失的地方？请结合刚才的操作说明。

热量设为 0 后分析，错误提示指出每日摄入热量，摘要明确显示“分类已生成，趋势未生成”，趋势体重卡也变成“未生成”；我实际点击“返回每日摄入热量”，输入框进入可见区域，80 kg 档案仍保留。恢复为 1800 再分析后，趋势及 +237 kcal 重现，无需重新导入；此时前后对比显示 32.7% → 32.7%，说明比较基准已随提交更新，建议明确标注“与上一次提交比较”，避免与 T4 的初始比较混淆。

## T6 提交反馈并浏览公平性审核

**从哪里开始：** 先留在体重管理页面，再通过侧栏进入审核页。

**操作步骤：**

1. 在“本次结果摘要”点击“填写用户反馈”，到达“理解自测与用户反馈”；选择操作容易程度，并按自己的理解完成页面上的单选题，建议可以留空。
2. 点击“保存本次反馈”，再点击“下载匿名反馈（JSON）”。
3. 在左侧“页面”选择“模型公平性审核”。
4. 在“查看群体”中先选择“女性”，再选择“男性”，最后回到“全部群体”。
5. 在“比较指标”中分别选择“漏判率 FNR”和“误判率 FPR”，查看对应图表与紧邻的分组指标表，浏览同时展示的基线模型和公平性约束方案。
6. 在左侧切回“体重管理原型”，查看之前的档案和结果。

**操作到这里结束：** 已试用反馈保存与下载，切换过审核页的群体和指标，并返回体重管理页。

**体验反馈：**

- 审核页哪些展示便于比较，哪些术语、图表或布局增加了负担？你希望怎样简化？已实际切换女性、男性、全部群体，再分别查看 FNR 与 FPR；默认分组表现在只突出方案、群体、样本量、漏判数、误判数和两种错误率，详细指标默认折叠且能展开，当前 EO 还补充了约 2.08 个百分点的解释。两方案仍为 EO 0.0208 → 0.0208、整体平衡准确率均 99.26%，本次没有改善；女性 204 条零错误、男性 216 条含两次漏判及一次误判不能推出完全公平，页面的不确定性说明也已查看。
- 页面切换和返回的体验是否符合预期？如有问题，请说明。返回后体重仍为 80.0 kg、摄入仍为 1800 kcal，摘要区分 80.0 kg 与 70.5 kg，分类仍正常体重、32.7%，趋势及反馈下载入口均保留，符合本次同一会话切换的预期。服务端同时出现 include_trend 控件状态警告，未阻断返回或趋势展示；刷新、关闭和跨会话恢复未测试。
