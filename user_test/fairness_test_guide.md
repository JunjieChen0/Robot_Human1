# 第二次作业：公平性页面测试指南

谢谢你帮忙测试。这次请体验“模型公平性审核”页面，看看能否找到所需信息、理解页面结论。预留约15分钟，安装环境的时间另计。不需要填写自己的身高、体重等健康信息。

请先完成本指南的四项任务，再阅读实验报告、原始结果文件、记录者说明或模拟录像，也先不要打开页面底部的“理解自测”。没有看懂或没有完成都可以如实记录。

## 1. 准备一份个人报告

打开[个人测试报告模板](fairness_report_template.md)，**先复制内容或下载文件，另存为副本，再开始填写**：

```text
公平性测试_P01_YYYY-MM-DD.md
```

`P01` 换成邀请者分配给你的代号，日期填写实际测试日。不确定代号时先询问邀请者。可以用记事本或常用 Markdown 编辑器填写，不需要提交姓名、学号或个人健康数据。四项任务请放在同一份报告里。

## 2. 下载并启动

需要 Python 3.11 和联网安装依赖。没有 Python 时先安装 Python 3.11；如果安装遇到困难，保留错误信息并联系邀请者，也可以由邀请者提供已经启动的电脑。

从仓库页面选择 **Code → Download ZIP**，解压后进入含 `app.py` 和 `requirements.txt` 的文件夹；已使用 Git 克隆也可以。请在解压后的文件夹中打开终端，不要直接在压缩文件窗口运行。

Windows PowerShell 依次执行：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

这些命令不需要激活虚拟环境。如果没有 `py` 命令，但 `python --version` 显示为3.11，可以把第一条换成 `python -m venv .venv`。

macOS / Linux 使用已安装的 Python 3.11：

```bash
python3.11 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
./.venv/bin/python -m streamlit run app.py
```

保持终端运行，在浏览器打开 <http://localhost:8501>。侧栏“页面”中选择 **模型公平性审核**。

初始页面是“体重管理原型”。如果那里提示模型文件尚未生成，直接从侧栏切换到公平性审核页即可；本轮不需要运行下载、预处理或训练命令。审核页会读取仓库已有的实验结果。

如果端口8501被占用，在启动命令末尾加 `--server.port 8502`，再打开 <http://localhost:8502>。测试结束后回到终端按 Ctrl+C 停止服务。

启动失败时，不要把后面的任务填成已完成。把运行的命令、完整错误文字或截图发给邀请者，报告中写明未能进入页面。

## 3. 怎样计时和记录

- 开始前填写报告中的日期、设备、浏览器和代码版本。Git 克隆可运行 `git rev-parse HEAD`；下载 ZIP 可复制仓库页面最新提交的编号，并记录 ZIP 文件名。使用邀请者提供的电脑时，由邀请者填写版本。
- 每项任务读完题目、准备开始操作时计时；找到信息并写完首次回答时停止。推荐由记录者计时；独自测试可使用手机秒表，或在录屏中明确每项任务的开始与结束位置，结束后据录像补记秒数，并注明计时依据。
- 遇到困难可以求助，但保留求助前的回答，记录提示次数及内容；任务时间包含求助和等待。约3分钟仍无进展时可以停止，按实际情况记录“部分完成”或“未完成”。
- 没有准确计时就填“未计时”，不要估造秒数。只有总耗时时单独填写，不能按任务数平分。安装和启动时间单独记录，不计入T1–T4；录屏可只截取本地应用页面，不需要包含其他窗口。
- 操作状态填写“独立完成 / 提示后完整完成 / 部分完成 / 未完成”。理解是否正确由记录者之后核对，测试者只写自己的首次回答和不确定之处。

## 4. 四项指定任务

请保留以下T1–T4的内容和对应关系。额外做的区间分析或改进方案讨论可以放在报告末尾，不能替代T3的模型对比或T4的指定回答；如果使用其他任务单，请记录来源和版本。

### T1：找到分组数据

使用“查看群体”分别查看女性和男性；在“各组数据是否可比”中，把“数据范围”设为“测试集”。

请在报告中填写两组的样本量、正类数、负类数和真实正类比例。说明两组数据是否完全相同，以及切换群体时哪些区域发生了变化。按页面实际展示记录即可，不需要重新计算模型。

### T2：查看漏判和误判

把“查看群体”切回“全部群体”，依次把“比较指标”切换为“漏判率 FNR”和“误判率 FPR”，同时查看下方表格及说明。

不需要预先掌握英文缩写，可以使用页面上的中文解释；不清楚的词也请记录下来。

请记录两组的漏判率、误判率和错误数量。用自己的话解释“漏判”和“误判”，并说明计算这两个比例时分别除以什么数量。哪一组在本次测试中出现了更多错误？

### T3：比较基线与约束方案

查看页面顶部的整体指标，再比较两组图表和表格；需要时可以展开“如何选择约束方案”。

基线和约束方案同时展示，不需要寻找“切换模型”按钮。切换群体或指标时，可以根据所选名称和图表标签确认当前视图；数值有无变化都按实际记录，不预设约束后一定改善。

请判断约束方案是否改善了群体差异、整体表现是否发生变化。写出支持判断的页面数字或提示；你觉得是否通过牺牲某一组的表现换取了改善？如果不能判断，也写明缺少什么信息。

记录数字时同时抄下完整指标名称，例如“平衡准确率”；不要把不同指标都简称为“准确率”。

### T4：解释结果和局限

展开“错误率的不确定性”，阅读“这些结果能说明什么”，然后先回答以下问题，不要打开“理解自测”：

1. 整体准确率约99%，能否由此说明不同群体表现一致？为什么？
2. 一组本次没有错误，能否说明它未来也不会出错？页面哪些信息支持你的判断？
3. 页面说明了哪些数据或适用范围限制？至少写出一项。

先保存首次回答并停止T4计时。之后再打开“理解自测”，选择你认为合适的选项，点击“查看解释”。在报告的补充栏写明自测前后是否改变了想法，不要覆盖首次回答。

## 5. 最后发回什么

完成模板末尾的简短反馈，至少写出一条具体建议，例如哪个词看不懂、哪项数据难找、希望哪处增加说明。请根据实际体验填写，不要求给正面评价。

通过邀请你测试的同学原来联系你的渠道，发回：

1. **一份填写好的 `公平性测试_代号_日期.md`**：含环境信息、T1–T4状态与时间、首次回答、提示记录和最后反馈。
2. **可选截图**：遇到报错、难以定位或其他问题时附上，并在报告中说明对应任务。没有问题无需为了交材料额外截图。

不用上传到公开仓库，也不用发环境文件、整个源码或重新写实验分析报告。若部分任务未完成，仍然返回这份报告，保留失败位置和原因。
