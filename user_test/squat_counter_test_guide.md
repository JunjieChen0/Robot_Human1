## 一 先固定规则与素材

阅读`docs/squat_counter_spec.md`。试录后固定阈值、版本与运行条件，记录浏览器/设备。性能测试用固定视频，以1倍速从头播到自动结束，不手工暂停、不修正；局部测试先剪成独立片段，不把完整片段的部分运行当完整评价。

三份原操作会话都有手动暂停，不能直接作为连续性能实验。新的连续会话应另外导出；原轨迹回放、技术控件试填5秒/15秒均不充当人工真值。若要声称v2更容易理解或更容易自行纠错，需另行邀请同学复测并保留版本、接触情况与首次原话；现有技术检查不支持此类使用效果提升结论。

至少覆盖normal（正常光照）、light_change（光线变化）、occlusion（局部遮挡）。每种可先录1段短片，包含若干完整站立—下蹲—站立、保持3秒、半蹲、遮挡及恢复；后续可增加片段和参与者。不要为制造改善而故意设计错误版本。

片头、片尾各保留至少1秒站立余量，让0.3秒确认及帧采样能够完成；被截断的动作单列，不能仅凭文件名“10次”作为真值。剪辑、重复片段和条件模拟方式要登记，不把重复输入当独立采集样本。

影像必须本人拍摄或得到用于本课程测试的同意，登记`user_test/squat_media_register.csv`。遮挡导致的漏计仍统计；人工也看不清时用辅助观察确认，无法确认的事件单列不确定，不能静默删除难例后夸大效果。

## 二 人工逐次标注

复制`user_test/squat_annotations_template.csv`，每条有效动作一行。`source_id`用导出JSON的`source.sha256`；摄像头记录用`session.id`，不可混用片段。`time_ms`以源片段时间轴标注完整动作恢复到约定站立条件的起点，尚未加300毫秒确认时间。

摄像头的源时间从打开摄像头后的视频轨道开始，不从按下“开始计数”重新归零；人工记录须使用页面显示的“片段时间”，不要换用另一个从按键开始的秒表。为便于逐帧核查，三种条件的识别性能评价优先使用事先获同意的固定视频。

`condition`同一个评价文件只能是normal、light_change或occlusion之一，事件ID唯一。正式评价前固定匹配窗口，默认1200毫秒，不能看过结果后仅为降低误计漏计而调窗口。人工标注应先于查看模型计数，保存初版，不复制预测事件作为真值。

```bash
python -m src.squat_evaluation --session S01.json --annotations manual.csv --output reports/squat_counter/evaluation_S01.json
```

工具对原始自动事件一对一匹配，先最大匹配数，再最小时间差。未匹配自动事件为误计，未匹配真实事件为漏计；使用修正前事件，即使修正总数相同也不抵消。超窗的迟到事件可能记为一误计加一漏计，需保留明细复核。

反馈延迟按匹配事件的`feedback_time_ms - time_ms`估计，含稳定确认与处理至后续渲染回调耗时；不是仅推理耗时，也不是光电屏幕实测。记录样本数、中位数、P95；缺失不填0，负值保留供复核。离线处理总耗时不能冒充实时反馈延迟。模拟关键点会话、未结束会话、不完整视频运行及含手动暂停/继续的会话被工具拒绝；关键点不清时的自动计数暂停仍保留在连续性能测试中。

## 三 三位同学独立操作

分别分配S01、S02、S03，转发`user_test/squat_counter_quickstart.md`，不提前展示预期次数或纠错步骤答案。每人完成一次开始—识别—暂停—继续—结束、核对计数、发现错误及自行纠正任务。原话与操作分开记，提示前首次答复与提示后补充分开。

逐人记录：实际日期、页面/代码版本、素材ID、任务完成情况、发现错误的具体时间、修正操作、是否自行完成、提示次数和内容、既往接触、设备浏览器、JSON及同意范围。缺失留空，不补造。

若现场没有自然错误，可用明确标记的旧版真实失败回放或纠错练习验证控件操作，单独标记其来源，不把模拟错误计入真实模型性能。不能因点了补记就推断已正确理解错误，也不能因最终总数相同就声称没有误计漏计。

## 四 真实失败与前后复测

保留原视频及SHA、首次模型输出/关键点轨迹、规则版本、人工标注和界面截图。分析视觉模型定位错误、规则触发错误或提示未理解，可能有多重原因，不凭总数猜原因。

修改后以新版本在同一片段、同一标注与窗口复测；条件有变化须另记，不能冒充完全相同。将原始误计/漏计/延迟和用户纠错表现分别对照。当前`user_test/squat_counter_before_after.md`已有同片段的程序行为技术对照；没有独立完成事件标注或真人改后结果，不能据此宣称识别准确率或使用效果提升。

## 演示视频

最终演示应展示获同意的实际输入、一次完整计数、保持不重复、看不清提示、暂停/继续、撤销与补记、结束及关闭摄像头。自动空画面/模拟关键点演示只能说明技术流程，需明确标记，不能替代真人动作识别演示。
