# 用户测试任务单（WeightTrend 减重趋势分析原型）

## 测试说明

本测试用于评价**减重趋势分析原型**是否容易操作和理解。参与者使用匿名编号记录，不填写姓名、学号或其他直接身份信息。

测试结果仅用于课程作业，不用于评价参与者的身体健康状况。

## 测试结束访谈

1. 哪一步最容易理解？
2. 哪一步最困难？
3. 你是否相信预测结果是绝对正确的？
4. 概率和适用范围说明是否清楚？
5. 如果只能改进一个地方，你建议改什么？

## 记录原则

- 使用 `P01`、`P02`、`P03` 等匿名编号；
- 不虚构完成率、操作时间或用户原话；
- 用户反馈原文如果可能暴露身份，应改写为匿名摘要；
- 用户测试结束后，再将记录汇总到 `test_record_template.csv`。
