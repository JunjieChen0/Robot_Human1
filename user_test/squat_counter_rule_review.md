# 深蹲候选动作有效性复核

已有15个由用户补充的人工候选站立时刻，不需要重复提交时间列表。本次只补充“是否符合约定计数规则”的裁定，以便将候选匹配定稿为误计、漏计及反馈延迟。

## 固定规则

按[原规则](../docs/squat_counter_spec.md)复核同一侧髋、膝、踝的二维夹角：初始站立≥160°稳定300毫秒，下蹲≤100°稳定300毫秒，恢复站立≥160°稳定300毫秒，才构成一次有效动作。保持不重复计数。这是课堂算法规则，不是体育动作标准。

独立查看源视频或原始联系图，不使用本次MediaPipe预测角度、计数或反馈决定真值。人工量角时可手动定位髋、膝、踝；稳定时间以该姿态首尾帧的源时间差判断，不能只凭一张最低点截图。遮挡中无法判断时保留`uncertain`，不要猜填有效或无效。

## 填写与返回

复制[JSON复核表](squat_counter_rule_adjudication_template.json)，填写匿名复核者、复核日期，并把每项`decision`改为`valid`、`invalid`或`uncertain`；写明简短依据。仅在独立复核后修改`confirmed_stand_ms`，无法确认的时间留`null`。原`candidate_stand_ms`保留用于追溯。

也可以在聊天中按以下格式回复，注明不同候选的判断及依据：

```text
复核者：匿名编号；日期：实际复核日期
正常光照：1有效/无效/无法判断，依据……；2……；3至5……
光线变化：1……；2……；3……；4至5……
局部遮挡：1……；2……；3……；4……；5……
```

所有`pending`都只是空白待填，不代表参与者回答。`uncertain`是人工无法确认，不能悄悄删除后只报有利分数。正式评分前须说明这些不确定事件如何处理；当前[假设敏感性分析](../reports/squat_counter/submission_20261121/README.md)不能替代人工裁定，也不能把有效候选附近的自动事件全部预先当作正确。
