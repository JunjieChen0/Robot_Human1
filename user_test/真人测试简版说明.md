# WeightTrend 真人测试简版说明

请邀请至少 **3 名同学**分别测试，每人预计 15–20 分钟。测试界面是否好用、结果是否容易理解，不评价同学的健康状况。

## 开始前

组织者提前启动界面，并提供[示例 CSV](../data/sample/profile_template.csv)。同学可以全程使用示例数据，不用填写真实健康信息。每人使用新的浏览器会话，先不要看参考答案或其他人的回答。

## 需要测试什么

| 任务 | 要做的操作和回答的问题 |
|---|---|
| T1 录入数据 | 导入示例 CSV，核对表单。说出身高、体重的单位，以及这些数据来自哪里。 |
| T2 查看结果 | 点击“估计并分析趋势”，找到分类结果、概率和体重趋势。用一句话说明模型在估计什么。 |
| T3 理解提示 | 阅读结果说明。回答：类别概率 80% 是否等于患病风险或绝对正确率？结果能否直接说明所有人的健康状况？为什么？ |
| T4 修改重算 | 把档案体重改为 80 kg，先不点击分析，观察提示及旧结果；再重新分析，找到修改前后对比。结果有没有变化？ |
| T5 处理错误 | 把每日摄入热量改为 0 后分析，查看错误提示；再恢复为 1800 并重新分析，或取消趋势分析。说明你怎样恢复操作。 |
| T6 反馈与审核 | 保存并下载匿名反馈。切到公平性页，切换女性、男性，查看样本量和漏判、误判，比较两方案。回答：本次约束有没有改善？某组零错误能否说明完全公平？最后返回体重页。 |

每项从**读完题目**开始计时，到完成操作并记录首次回答时停表，安装时间不计入。先记录自己的回答，再查看页面自测解释；需要帮助可以提出，并记录求助次数。
