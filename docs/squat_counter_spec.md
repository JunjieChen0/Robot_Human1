# 深蹲计数场景与验收规则

页面版本：`squat-counter-v1`。面向大学生宿舍/课间单人锻炼。任务是完成10次约定深蹲，读懂反馈、核对并修正误计或漏计，再结束并关闭输入。固定侧面视角，仅选择靠近镜头的一侧，肩、髋、膝、踝完整入镜。界面不评价动作标准，不从次数推断热量、体重或健康结论。

## 计数定义

1. 先观察站立：选定侧的髋—膝—踝二维夹角≥160°持续300毫秒，才进入准备状态。开始时已下蹲不计数。
2. 夹角≤100°持续300毫秒，确认下蹲；保持3秒或更久不重复计数。
3. 此后恢复≥160°并持续300毫秒，记录一次完整动作。未达到下蹲条件的半蹲不计数。中间角度不触发，阈值抖动会重新开始稳定确认。
4. 任一所需关键点可见度/存在度低于0.65、出画面边缘、没有人、多人或退化几何，暂停计数并提示调整。视频仍可播放，原有次数保留。
5. 手动暂停、关键点不清、时间倒退或相邻帧间隔超过500毫秒，清除未完成动作，恢复后先重新站立。不能把遮挡/暂停前的下蹲与恢复后的站立拼接计次。
6. 左右侧按本人身体命名，预览不镜像。二维角度先按画面宽高还原像素比例；不是直接在归一化x/y上计算。侧面、投影与遮挡仍限制角度可靠性。

这些是初始课堂计数条件，尚未通过真实视频确认。正式性能测试前应试录、固定规则并记录版本；不能用正式测试片段反复调阈值后仍称独立测试。

## 交互与纠错

- 导入视频或打开浏览器摄像头前确认本人影像/已获同意。首次下载模型后，在本机浏览器处理，原画面不上传Python服务，默认不录制。
- 开始、暂停、继续、结束、关闭摄像头均为明确按钮。暂停时摄像头仍可能开启，状态会写明；结束/关闭输入会停止媒体轨道及推理线程。
- 暂停或结束后可回看视频；回看不识别、不加次数。继续时回到暂停位置并重新站立准备。重新计数会新建会话，先导出需保留的结果。
- 自动事件始终保留。撤销选中误计、补记漏计、撤销上次修正均追加历史；自动计数与修正后计数分开显示。
- 初次反馈为参与者自报，保存后锁定；不自动判定其是否发现错误或自行纠正。下一位同学使用新的浏览器会话。

## 可检验的成功条件

规则层：站立—下蹲—站立一轮只加1，保持与抖动不额外计数，看不清/暂停后不拼接动作；回看不重复计数；纠错不覆盖原始事件。

界面层：用户能独立开始、暂停、继续、看懂状态、定位需修正事件并结束/关闭输入。结果以本次三名同学的操作证据记录，旧任务记录不能代替。

视觉层：必须使用获同意的真实片段，在正常光照、光线变化、局部遮挡下逐次标注，分别报告误计、漏计与反馈延迟。模拟关键点和空画面检查不代表真实深蹲识别效果。
