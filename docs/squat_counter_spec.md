# 深蹲计数场景与验收规则

当前页面版本：`squat-counter-v2`；三名同学的原始首测均为v1，原件保留。面向大学生宿舍/课间单人锻炼。任务是完成10次约定深蹲，读懂反馈、核对并修正误计或漏计，再结束并关闭输入。固定侧面视角，仅选择靠近镜头的一侧，肩、髋、膝、踝完整入镜。界面不评价动作标准，不从次数推断热量、体重或健康结论。

## 计数定义

1. 先观察站立：选定侧的髋—膝—踝二维夹角≥160°持续300毫秒，才进入准备状态。开始时已下蹲不计数。
2. 夹角≤100°持续300毫秒，确认下蹲；保持3秒或更久不重复计数。
3. 此后恢复≥160°并持续300毫秒，记录一次完整动作。未达到下蹲条件的半蹲不计数。中间角度不触发，阈值抖动会重新开始稳定确认。
4. 任一所需关键点可见度/存在度低于0.65、出画面边缘、没有人、多人或退化几何，暂停计数并提示调整。视频仍可播放，原有次数保留。
5. 手动暂停、关键点不清、时间倒退或相邻帧间隔超过500毫秒，清除未完成动作，恢复后先重新站立。不能把遮挡/暂停前的下蹲与恢复后的站立拼接计次。
6. 左右侧按本人身体命名，预览不镜像。二维角度先按画面宽高还原像素比例；不是直接在归一化x/y上计算。侧面、投影与遮挡仍限制角度可靠性。

v2保留上述阈值及模型，仅在稳定时间比较时容忍`1e-6`毫秒浮点换算误差，修复十进制300毫秒被表示为299.999999999998毫秒的边界问题；299.9毫秒仍不确认。此为数值修复，不是降低动作保持时间。

这些是初始课堂计数条件，尚未通过真实视频确认。正式性能测试前应试录、固定规则并记录版本；不能用正式测试片段反复调阈值后仍称独立测试。

## 交互与纠错

- 导入视频或打开浏览器摄像头前确认本人影像/已获同意。首次下载模型后，在本机浏览器处理，原画面不上传Python服务，默认不录制。
- 开始后自动检查站位，视频以1倍速自动播放；界面说明无需单独站位按钮。暂停时摄像头仍可能开启，状态写明；结束/关闭输入停止媒体轨道及推理线程。视频播放完自动结束，无需再点击结束。
- 暂停或结束后可回看视频；回看不识别、不加次数。继续时回到暂停位置并重新站立准备。重新计数会新建会话，先导出需保留的结果。
- 自动事件始终保留。撤销选中误计、补记漏计、撤销上次修正均追加历史；自动计数与修正后计数分开显示。v2保留文件结束位置，回看条与“漏计动作完成时刻”输入同步，支持精确到0.001秒的手工选时并拒绝负数、超范围值；默认是当前位置，不自动推断真实漏计时刻。摄像头关闭后保留片段时钟上限，默认不保存画面。
- 初次反馈为参与者自报，保存后锁定；不自动判定其是否发现错误或自行纠正。下一位同学使用新的浏览器会话。

## 可检验的成功条件

规则层：站立—下蹲—站立一轮只加1，保持与抖动不额外计数，看不清/暂停后不拼接动作；回看不重复计数；纠错不覆盖原始事件。

界面层：用户能独立开始、暂停、继续、看懂状态、定位需修正事件并结束/关闭输入。结果以本次三名同学的操作证据记录，旧任务记录不能代替。

视觉层：使用来源与授权明确的视频，在正常光照、光线变化、局部遮挡下逐次对照参照事件，分别报告误计、漏计与反馈延迟。作业允许导入测试视频，未限定必须是真人实拍；采用生成或后期处理素材时披露制作方法和适用范围。当前材料采用用户人工候选时刻与AI辅助有效性判读，无法判断的动作单列并给出误差范围，不冒充完整独立人工真值评分。模拟关键点和空画面检查仅验证程序行为，合成输入的实际模型推理也不代表真实场景泛化效果。
