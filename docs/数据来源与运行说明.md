| 数据集标签 | 界面中文名 |
| --- | --- |
| Insufficient_Weight | 体重偏低 |
| Normal_Weight | 正常体重 |
| Overweight_Level_I | 超重 I 级 |

### 1.4 两项未采集字段的填充口径

`CH2O`（每日饮水量）与 `TUE`（每日电子设备使用小时数）在模型训练时是特征，但原型不向用户采集——普通用户难以准确自报这两项。预测时由 `app.py::fill_imputed_features` 按**训练集中位数**填充：

| 字段 | 填充值（训练集中位数） |
| --- | --- |
| CH2O | 2.0 |
| TUE | 0.634 |

如此模型输入仍为完整 19 维。该口径在界面三处披露：表单顶部说明、「📖 使用说明」第 8 条、特征重要性表下方注释。实测 7 个演示档案在中位数填充下仍全部判定正确。

不变量由 `tests/test_preprocess.py::test_form_and_imputed_features_cover_all_numeric_features` 锁定：表单采集字段与填充字段互不重叠，且并集恰等于全部数值特征。

### 1.5 备选与未采用的数据源

| 候选 | 类型 | 规模 | 许可 | 结论 |
| --- | --- | --- | --- | --- |
| **UCI 544**（上表） | 横断面个体级 | 2111 × 17 | CC BY 4.0 | **采用**：输入结构与原型录入项一致，且带肥胖等级标签 |
| CDC BRFSS（营养、身体活动与肥胖） | 横断面调查，聚合级 | 大 | ODbL | 备选：只适合做人群趋势背景，缺个体级建模粒度 |
| NHANES（24h 膳食回顾 + PAQ + 体格测量） | 横断面个体级 | 大 | 公开 | 备选：清洗成本高、收益不明确 |
| 纵向个人体重 + 饮食 + 运动日志 | 时间序列 | — | — | **未找到公开可用数据** |

检索覆盖 UCI、Kaggle、data.gov、PhysioNet 方向与量化自我文献。核心结论：**同时包含「纵向体重记录 + 饮食 + 运动」的公开数据集不存在**，因此体重趋势部分不能建立在训练数据上（处理方式见 1.9）。

### 1.6 数据质量与异常值处理

**完全重复行**：33 行分属 9 个重复组，其中冗余 24 行（`data/processed/data_quality.json` 的 `duplicate_full_rows`）。处理口径为**保留不删除**，但划分时以重复组为单位整体分配——`src/preprocess.py::assign_splits` 先按「19 维特征 + 标签」识别重复组，用每组的 leader 行参与分层划分，组内成员跟随 leader。实测 **0 组跨划分**，消除了训练/测试之间的数据泄漏。对应用例：`tests/test_preprocess.py::test_assign_splits_keeps_duplicate_groups_in_same_split`。

**异常值检测**（`src/preprocess.py::detect_outliers`，产物 `reports/tables/outlier_summary.json`）采用双口径：

| 字段 | 领域边界 | 领域越界值 | IQR 离群点 |
| --- | --- | ---: | ---: |
| Age | 14 – 70 | 0 | 168 |
| Height | 1.4 – 2.2 | 0 | 1 |
| Weight | 30 – 200 | 0 | 1 |
| FCVC | 1 – 3 | 0 | 不计算 |
| NCP | 1 – 4 | 0 | 不计算 |
| CH2O | 1 – 3 | 0 | 不计算 |
| FAF | 0 – 3 | 0 | 不计算 |
| TUE | 0 – 2 | 0 | 不计算 |

- **问卷字段**（FCVC / NCP / CH2O / FAF / TUE）的取值范围本身就是问卷语义（如 FAF 0–3 表示运动频率等级），分布偏斜会让 IQR 把合法边界值误报为离群点，故**只做领域边界校验**，结果为 0 个领域非法值。
- **连续字段**（Age / Height / Weight）额外报告 IQR 离群点。Age 的 168 个"离群点"实为 35–61 岁的合法样本，恰好佐证健康问卷数据不能机械套用 IQR 截尾。
- 最终处理：**保留全部 2111 个样本，不做删除或截尾**，并在报告中论证理由。

**缺失值**：0 个，无需插补。

### 1.7 数据划分与防泄漏

| 项 | 口径 |
| --- | --- |
| 划分比例 | 按标签分层 60 / 20 / 20 |
| 实际规模 | 训练 **1270** / 验证 **421** / 测试 **420** |
| 用户分组 | 数据集无受试者编号，故不做按用户分组 |
| 重复行 | 按组整体划分（见 1.6），0 组跨划分 |
| 随机种子 | `RANDOM_STATE = 42`（`src/config.py`），固定划分与训练随机性 |
| 测试集用途 | **仅**由 `src/evaluate.py` 读取用于最终评价；不参与训练，不参与超参选择 |
| 最终模型训练集 | 选型确定后，在训练集 + 验证集合并的 **1691** 条样本上重训（`src/train.py`），测试集始终未参与 |

模型选择只用验证集：LogisticRegression 与 RandomForest 在同一训练集上拟合，按验证集 macro-F1 选型（见 3.4 判据）。

### 1.8 数据局限

1. **合成样本导致乐观偏差**：UCI 544 的问卷部分来自哥伦比亚 / 秘鲁 / 墨西哥人群，其余大部分为 SMOTE 合成扩充样本（据数据集论文）。合成样本使类别边界比真实人群更"干净"，因此 0.94 量级的准确率存在乐观偏差，不能直接外推到真实人群。
2. **横断面而非纵向**：数据是一次性调查，无法支撑"个人未来体重变化"的因果推断。原型的等级估计只表示模型对当前录入的类别归属，界面在「解释反馈」区明确写出这一点。
3. **模型高度依赖体格信号**：全局特征重要性前几位为 Weight 0.326、Height 0.097、Age 0.095、FCVC 0.091、Gender 0.057，说明判定主要由体重/身高/年龄驱动，饮食与运动类行为特征的边际贡献较小。界面同时声明"特征重要性是模型整体属性，不等于某一次估计的因果解释"。
4. **两项特征由中位数填充**：CH2O 与 TUE 不参与真实采集（见 1.4），对个体差异不敏感。

### 1.9 趋势部分为何不依赖训练数据

因公开纵向数据缺失（见 1.5），体重趋势改为两条不依赖训练集的路径：

- **记录期变化**：由用户自报的多次体重记录直接计算，属描述性分析（`app.py::show_trend`）。
- **未来 90 天外推**：由解析能量平衡模型给出（`src/energy.py`）——Mifflin-St Jeor 基础代谢 × 活动系数 = TDEE，每日能量差 = 消耗 − 摄入，按 7700 kcal 折合 1 kg 线性外推。

其数学关系由 `tests/test_energy.py` 做解析自洽验证（BMR 参考值、活动档位阈值、TDEE 单调性、能量差方向）。外推属**示意性预测**，界面标注"仅用于趋势参考，不作为医学诊断"。

活动水平由 FAF（0–3）映射，档位阈值为 1 / 3 / 5，因此在当前录入范围内**「高度活动」不可达**，最高只能得到「中度活动」（系数 1.55），每日消耗估算相应偏保守。该口径已在界面 FAF 字段说明中披露。

| 原型服务 | `http://localhost:8501/_stcore/health` 返回 `ok` |

`RANDOM_STATE = 42` 固定了划分与训练随机性，按上述顺序重跑应复现同样的指标。

### 3.5 离线环境兜底

1. 从 1.1 的官方链接下载压缩包；
2. 保存为 `data/raw/uci544.zip`；
3. 重新运行 `python -m src.download_data`——脚本检测到有效压缩包后跳过下载，直接解压到 `data/raw/uci544/`；
4. 解压后必须存在 `data/raw/uci544/ObesityDataSet_raw_and_data_sinthetic.csv`；若压缩包内部结构不同，脚本会报错并打印该期望路径，按路径手动放置即可。

数据就位后，`src.preprocess` 及之后的所有步骤均为本地计算，不再需要网络。

### 3.6 常见报错

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `数据下载失败（已重试 3 次）` | 无网络或远端提前关闭连接 | 按 3.5 手动放置压缩包，报错信息中已含 URL 与目标路径 |
| `解压后没有找到预期的 CSV 文件：<路径>` | 压缩包内部结构与预期不同 | 按报错打印的路径手动放置 CSV |
| `没有找到处理后的数据，请先运行 python -m src.preprocess` | 跳过流水线直接训练 | 按 3.3 顺序执行 |
| `请先运行预处理和训练步骤` | `models/` 或 `data/processed/` 缺失 | 按 3.3 顺序执行 |
| 原型红框「原型所需文件尚未生成」 | `models/` 或 `data/sample/` 缺失 | 红框内已打印需执行的命令 |
| `编码后存在无法识别的取值，涉及列：[...]` | 录入了映射表外的类别值 | 检查下拉框取值是否被改动 |
| `表单分区字段与采集字段不一致` | 改了 `PROFILE_SECTIONS` 或字段定义但两边不同步 | 使 `app.py` 的分区字段与 `FORM_FIELDS` 一致 |
| 端口 8501 被占用 | 已有旧实例在跑 | 关掉旧进程，或加 `--server.port 8502` |
