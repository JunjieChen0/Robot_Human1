# 三条件视频的AI辅助复核与统计口径

复核日期：2026-11-21。用户已提供15个“人工候选站立起点”和浅蹲、遮挡、拼接等备注，随后明确要求由AI助手补写有效性分析。本记录由AI助手完成源帧视觉筛查，不是新增同学测试或独立人工量角。

素材来源：同组同学提供。保留原说明：三段为Grok Imagine生成的虚构人物，视频经过剪辑，亮度变化和色块遮挡为后期效果。影像只用于本地课程材料。

## 方法

保持原规则：下蹲二维膝角≤100°、站立≥160°，分别稳定至少300毫秒。24fps视频中，9个连续帧的首尾跨度为333.3毫秒。查看最低点前后9帧及候选站立起点后约125毫秒开始的9帧窗口；遮挡第2次另查看8.4167至8.875秒的连续帧。取帧未叠加或调用MediaPipe关键点，原候选时刻不改写，精度未知处不补造数值。

视觉支持明显屈膝且稳定、随后站立保持的动作暂定有效；阈值附近的浅蹲与关键关节被遮住的动作保留不确定。这里没有独立人工量角，全部决定都属于AI辅助筛查。原[人工候选记录](../../../user_test/squat_synthetic_human_reference.json)、[空白人工复核模板](../../../user_test/squat_counter_rule_adjudication_template.json)与[本次AI辅助记录](../../../user_test/squat_synthetic_assisted_review.json)分开保存。

## 误计、漏计与反馈延迟

固定既有1200毫秒一对一匹配窗口，复用六次完整连续模型会话，不使用手工修正后的总数。固定本次AI辅助明确项，对每项不确定动作穷举有效/无效组合，每次重新匹配全部自动事件；没有静默删除难例。范围只表达标签不确定性，不是置信区间，不能外推为真实环境表现。

| 正常光照/左侧 | 0 | 3/0/2 | 0 | 3–5 | 无样本，null |
| 正常光照/右侧 | 5 | 3/0/2 | 0–2 | 0 | 477.7毫秒（3） |
| 光线变化/左侧 | 0 | 2/0/3 | 0 | 2–5 | 无样本，null |
| 光线变化/右侧 | 5 | 2/0/3 | 0–3 | 0 | 450.5毫秒（2） |
| 局部遮挡/左侧 | 0 | 2/1/2 | 0 | 2–4 | 无样本，null |
| 局部遮挡/右侧 | 2 | 2/1/2 | 0 | 0–2 | 451.1毫秒（2） |

例如正常光照的两项浅蹲若都有效，右侧误计为0；若都无效，相应两个自动事件计作误计，不能只减少参照数而仍当预测正确。遮挡第1、5次若有效，右侧最多漏2次；若无法证实，则保留范围，不直接写成已确定漏计。

延迟只基于7项暂定有效且成功匹配的事件，仍采用用户原站立起点；以源时间加处理至后续渲染回调的耗时估计，包含稳定确认偏移。它不是纯推理耗时或屏幕光电实测，也不能冒充独立人工确认的完整延迟指标。原全部候选的时间统计另存，不能与本表的3/2/2个样本混用。
